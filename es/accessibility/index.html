Accesibilidad

Papito Blessedhands se compromete a que tanto este sitio web como el estudio en Grapevine sean acogedores y usables para todos, incluidas las personas con discapacidad.

El sitio web

Este sitio está construido con prácticas de accesibilidad modernas: encabezados semánticos, menús navegables por teclado, estados de foco visibles, contraste de color suficiente, enlaces descriptivos y soporte para movimiento reducido. Lo revisamos con regularidad y agradecemos tus comentarios.

El estudio

Si tienes necesidades de accesibilidad específicas para tu visita, avísanos al reservar y haremos lo posible por atenderlas.
